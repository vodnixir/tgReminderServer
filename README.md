# Телеграм-напоминалка от своего имени

Userbot на [Telethon](https://docs.telethon.dev/): отправляет напоминания
**с вашего личного аккаунта** — себе в «Избранное» или другим людям.
Управление — командами, которые вы пишете сами себе в «Избранное».
Поддерживает повторения (каждые N минут/часов/дней, заданное число раз
или бессрочно). Рассчитан на постоянную работу на Raspberry Pi.

## Как это работает

- Приложение входит в Telegram как обычный клиент (протокол MTProto),
  поэтому сообщения выглядят так, будто вы написали их сами.
- Напоминания хранятся в SQLite (`reminders.db`).
- Дальние напоминания (больше ~15 секунд до срока) скрипт ставит в родной
  планировщик Telegram («запланированные сообщения»): их доставляет сам
  сервер Telegram — секунда в секунду и даже если Raspberry Pi в этот
  момент выключен. Напоминания себе при этом приходят как «Напоминание»
  из «Избранного» — **с пуш-уведомлением на телефоне**.
- Совсем короткие напоминания и быстрые повторы (интервал меньше ~15 с)
  скрипт шлёт сам, точно в срок.
- Команды читаются только из вашего чата «Избранное» (Saved Messages) —
  никто другой управлять напоминалкой не может.

## Шаг 1. Получить API-ключи

1. Зайдите на https://my.telegram.org под своим номером.
2. Откройте «API development tools», создайте приложение (название любое).
3. Скопируйте `api_id` и `api_hash`.

## Шаг 2. Первый запуск (на любом компьютере)

```bash
python -m venv venv
venv\Scripts\activate        # Windows;  на Linux: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env       # Linux: cp .env.example .env
# впишите в .env свои API_ID и API_HASH
python main.py
```

При первом запуске Telethon спросит номер телефона, код подтверждения из
Telegram и, если включена, облачную двухфакторную аутентификацию (пароль).
После этого появится файл `reminder.session` — дальше вход автоматический.

> **Файл `reminder.session` — это полный доступ к вашему аккаунту.**
> Не выкладывайте его никуда и не коммитьте в git (он уже в `.gitignore`).

Проверьте, что всё работает: напишите себе в «Избранное» `/помощь`.

## Шаг 3. Перенос на Raspberry Pi

```bash
sudo apt update && sudo apt install -y python3-venv
# скопируйте проект на «малину», например:
#   scp -r tgproj pi@raspberrypi.local:/home/pi/
cd /home/pi/tgproj
python3 -m venv venv
venv/bin/pip install -r requirements.txt
```

Файлы `.env` и `reminder.session` можно скопировать вместе с проектом —
тогда логиниться заново не придётся. Либо запустите `venv/bin/python main.py`
один раз вручную и войдите с этого устройства.

Проверьте часовой пояс — напоминания используют локальное время хоста:

```bash
timedatectl                                  # посмотреть текущий
sudo timedatectl set-timezone Europe/Moscow  # поменять при необходимости
```

Автозапуск через systemd:

```bash
sudo cp deploy/tgreminder.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tgreminder
journalctl -u tgreminder -f    # смотреть логи
```

## Команды

Все команды пишутся **самому себе в «Избранное»**.

```
/напиши <кому> <когда> [каждые <интервал> [<повторений>]] / <текст>
```

| Часть | Варианты |
|---|---|
| кому | `я` — себе; `@username` — человеку из ваших чатов |
| когда | `09:00` (ближайшее), `07.07 09:00`, `07.07.2026 09:00`, `через 1ч30м` |
| интервал | `30с`, `45м`, `2ч`, `1д` и сочетания: `1ч30м`, `1д12ч` |
| повтор | `каждые 1д` — бессрочно; `каждые 2ч 5` — всего 5 отправок |

Примеры:

```
/напиши я через 30м / Выключить духовку
/напиши я 09:00 каждые 1д / Зарядка!
/напиши @ivan 07.07 12:00 каждые 1ч30м 3 / Пришли, пожалуйста, документы
/список
/удали 3
/помощь
```

## Пуш-уведомления

Дальние напоминания себе приходят с уведомлением сами — их доставляет
планировщик Telegram как «Напоминание» из «Избранного».

Исключение — совсем короткие напоминания (меньше ~15 секунд до срока)
и быстрые повторы: их скрипт отправляет напрямую со своего аккаунта,
а о собственных сообщениях Telegram не уведомляет. Если хотите пуш и для
них, подключите бота:

1. Напишите в Telegram боту **@BotFather** команду `/newbot`, задайте имя
   и username — получите токен вида `123456789:AAE...`.
2. Впишите его в `.env`: `BOT_TOKEN=123456789:AAE...`
3. **Откройте чат со своим новым ботом и нажмите «Start»** — без этого
   бот не имеет права писать вам первым.
4. Перезапустите скрипт.

## Ограничения и безопасность

- **Не используйте это для спама.** Telegram блокирует аккаунты за массовые
  рассылки людям не из контактов. Приложение делает паузу между отправками
  (`SEND_DELAY`, по умолчанию 4 с) и уважает лимиты Telegram (FloodWait),
  но здравый смысл оно не заменит: шлите напоминания только тем, кто их ждёт.
- Автоматизация личного аккаунта формально ограничена правилами Telegram —
  для личных напоминаний в разумных объёмах проблем обычно нет, но риск
  (вплоть до блокировки аккаунта) вы принимаете на себя.
- Если напоминание не отправилось (нет сети и т.п.), оно повторится через
  5 минут. Пропущенные за время выключения повторы не «догоняются» — берётся
  ближайшее будущее время по расписанию.
- Поставленные напоминания видны в самом Telegram: чат → меню →
  «Запланированные» / «Напоминания». Удаляйте их командой `/удали`,
  а не вручную из этого списка — иначе скрипт будет считать, что
  напоминание доставлено.
