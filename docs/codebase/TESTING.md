# Проверки и тестирование

## Стек и команды

- Используется стандартный `unittest` Python; дополнительные тестовые пакеты не нужны.
- Запуск: `python -m unittest discover -s tests -v` в подготовленном окружении.
- Покрытие и порог покрытия не настроены `[TODO]`.

## Расположение и изоляция

- Тесты находятся в `tests/test_commands.py`, `tests/test_control.py`, `tests/test_scheduler.py`.
- SQLite использует `:memory:`; Telegram-клиент и тема заменены имитациями, сетевые вызовы не выполняются.

## Уровни проверки

| Уровень | Покрыт | Что проверяется |
|---|---|---|
| Модульный | да | Разбор времени и длительности, отчёты и переход повторов |
| С имитацией Telegram | да | Тема, выбор адресата, отсутствие серверного планирования |
| Живой Telegram | нет `[TODO]` | Поиск реальной темы, обновления и доставка |
| E2E/systemd | нет `[TODO]` | Запуск Raspberry Pi, восстановление сети |

## Сигналы качества

- Во время разработки 16 тестов прошли локально с Telethon 1.45.0; это не проверяет поведение реального аккаунта.
- Ключи и сессия Telegram не предоставлены, поэтому живой запуск не проводился.
